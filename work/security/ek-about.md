# ek-about threat model (2026-11-06)
- **Assets:** the design team's narrative (brief.about.blocks: title <=80, text <=2,000 then cut with "…", note <=300, source_slide), shown verbatim in markup; per-paragraph "matters" votes, notes and voice clips stored under target `<title> ¶n` in the shell's `localStorage['ek:'+slug]`.
- **Actors:** visitor on own/shared phone; hostile visitor (devtools, planted store, other page on the same github.io origin); deck author / ingest model (controls every brief string); the team reading the export.
- **Entry points:** brief.about.blocks (or a bare list) -> `blocks_from_brief()`; `EK.reactions()` -> `render()`; the bar; the tour (`registerTour`, step 2 clicks the real Underline button).
- **Spoof:** the splitter only regroups sentences; `paragraphs_of()` checks the paragraphs rejoin to the brief's words and otherwise shows one paragraph, so no wording is invented. The 2,000-char cut is marked ("The rest of this text is in the presentation") and logged. A block `note` is italic team text under "From the presentation, slide n", visually distinct but read by a screen reader in the same run.
- **Tamper:** every brief string is `html.escape`d (text and quoted attributes: `data-target`, `data-label`, `aria-label`); inline `AB` holds only a count, via `json_inline`. Visitor values render with `textContent`; voice needs `audio/*` MIME and base64 alphabet. No `innerHTML`/`eval`/`on*=`.
- **Repudiate:** each block prints its slide or "slide not recorded". Notes on a vanished paragraph (re-split brief) stay visible under "Your notes on the plan as a whole"; but re-splitting renumbers `¶n`, so old votes silently attach to a different paragraph.
- **Disclose:** nothing personal collected. Export carries `<title> ¶n` only, never the paragraph text (through `tx`). Real build: 5 blocks, none cut, no named individuals found.
- **Deny:** <=12 blocks x 2,000 chars bounds the markup; render is O(paragraphs x reactions) per event.
- **Elevate:** reads --brief/--out, writes --out; stdlib; no subprocess, network or credentials.
- **Open:** tour step 2 calls `b.click()`, so the demo underline is an ordinary record without `tour:true`: a tab closed mid-tour leaves it in the store and the export as the visitor's vote (fix: `EK.react({...,tour:true})` directly). Shell `exit()` removes every record made since the tour started, including the visitor's own mid-tour notes.
