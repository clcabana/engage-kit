# Threat model: ek-site-story (2026-11-04)
- **Assets:** place names (≤60 chars), `text` (≤400), `source_slide` from the deck; the deck's photographs embedded as `data:` URIs in `<img>` (SVG regex-screened, rasters re-encoded through Pillow: ≤1400 px, EXIF dropped); the inline `PL` JSON (count only); visitor keep/change votes (`kind:'vote'`, value `'keep'|'change'`) and notes/clips per place name in `localStorage['ek:'+slug]`; any file with an image extension under `--root`.
- **Actors:** anonymous visitor (real project: 19 people on their own phones, photographed on their own site); hostile visitor (devtools, planted store); hostile deck author / ingest model (controls every brief string, `image` paths and the `people`/`cleared` flags); whoever edits the brief and sets `cleared`; design team running `build.py --root`.
- **Entry points:** `brief.places[]` → `places_from_brief()` (build.py:104-140) → `section_html()` (143-179); image bytes under `--root` → `embed_image()` (51-99), reached only after the `people`/`cleared` test at 128; `--root`/`--brief`/`--out` (operator); `EK.reactions()` → `voteOf()`/`render()` (235, 263-273); the vote buttons (256-260) and the tour (279-283), which clicks the real Keep button on scene 0; no `location.hash`, no network.
- **Spoof:** n/a — no identities; every scene prints its slide or "slide not recorded".
- **Tamper:** brief strings are `html.escape`d in text (`.pl-name`, `<p>`, slide line, rail label) and quoted attributes (`data-target`, `data-slide` (double-escaped, cosmetic), three `aria-label`s); `data-i` is the enumerate index; `src` is build-made (allowlisted MIME, base64). The script is `textContent`/`createElement`/`setAttribute` only; no `innerHTML`, `eval`, `Function`, `on*=`. `voteOf` accepts exactly `'keep'` or `'change'`, last wins; voice records need `audio/` MIME and base64 alphabet. SVG shown through `<img>` cannot run script; the pre-check now also catches `javascript:`, `<!ENTITY`, `<foreignObject`, `<?xml-stylesheet`, `url(http…)` (the gaps noted for ek-timeline on 2026-10-25 are closed in both copies).
- **Repudiate:** slide per scene; duplicate place names are warned (reactions target by name).
- **Disclose:** the gate at build.py:128 runs before any filesystem access, but it is self-declared by the same untrusted brief: a place with `people` absent or false embeds with no review, and `cleared` is tested for truthiness, so `"cleared": "no"`, `"pending"`, `"TBC"` or `1` all embed the photograph; the result is a warning, not a failed build, and the JSON summary does not say which embedded images were flagged `people`. Containment: UNC, absolute, drive-relative and `\`-rooted paths refused before any I/O; `resolve()` + parents check refuses `..` and junctions that leave `--root`. Without Pillow a raster ships verbatim with EXIF (GPS, device serial, owner) under a warning only; Pillow 13.0.0 is installed on this machine. ek-timeline embeds the same kind of photographs with no people gate at all.
- **Deny:** tour step 2 (build.py:281) calls the real Keep handler, whose first line deletes the visitor's own existing vote on place 0 (an existing Keep toggles off, so `undo` finds nothing); the shell's tour exit removes only records created during the tour, so a visitor who voted before watching the tour loses that vote silently. Vote clicks remove the old choice before `react`; on a full store the toast is honest but the old choice is gone. Rail labels are `white-space:nowrap`: at 375 px a 23-char name makes the rail 200 px wide and overlaps the caption by 96 px (vote buttons still reachable); a 60-char name runs off the left edge; `scrollWidth` stays 375. A raster between 89 and 178 Mpx decodes (Pillow warns) on the team's machine; above that `DecompressionBombError` is caught and the image skipped.
- **Elevate:** `build.py` reads `--brief`, `--out` and image files under `--root`; imports Pillow if present; writes `--out` only; no subprocess, network, env or credentials; nothing read is executed.
