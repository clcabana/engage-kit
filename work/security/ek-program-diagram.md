- **Spoof:** n/a — no identities; a stored rank/edit is "you" to whoever next holds the phone (shell welcome card and Remove all cover it).

- **Elevate:** `build.py` reads `--brief` and `--out`, writes `--out`; stdlib only, no subprocess, network, env or credentials; it never executes anything it reads. No external script; `CSS.escape`/`ResizeObserver` are platform.
