# Threat model: ek-chat (build.py, worker.js, PROXY.md; 2026-11-13)
- **Assets:** the creator's Anthropic key (Worker secret, or `localStorage['ek:<slug>:apikey']` in direct mode) and the account's spend; the system prompt (brief facts incl. client, location, `still_to_confirm`, readable in page source and `EK.chat.systemPrompt`); `question` records `{q, a, at}` (2,000 chars each) in `ek:<slug>`; the day counters (`ek:<slug>:chatday`, KV `day:<date>`).
- **Actors:** visitor; hostile visitor with devtools or curl; anyone who reads the proxy URL from the page; other pages/scripts on the same origin (clcabana.github.io: sample, demo, other repos' Pages); the person on the admin browser; Anthropic and Cloudflare (see every question; Anthropic retains per its API terms); the model that wrote the code.
- **Entry points:** visitor text (input 2,000, `ask()` 8,000/msg, last 12); the bracketed page note (section title + target, 120); brief strings (trimmed, JSON, `<`/`>` escaped, build.py:95); `o.system` passed by any caller (admin, voice redraft); the proxy request body; upstream responses/SSE; the typed key.
- **Prompt injection:** a visitor can steer only her own answer (no tools, no links, no HTML: answers and errors go to `textContent`, build.py:251-259); brief text cannot close `<project_facts>`. Stored `q`/`a` later reach the admin assistant as data (see ek-admin.md). Accepted.
- **Spoof (Worker):** `Origin` is the only gate (worker.js:30-39); curl sets any Origin. The Worker accepts the caller's `system` (60,000 chars) and any 24 messages, so the endpoint is a general-purpose LLM relay on the creator's key: up to 120 KB (~30k tokens in, 2,048 out) per call. **Fix:** do not take `system` from the body unless `sha256(system)` is in env `SYSTEM_SHA256` (comma list printed by build.py for the page prompt and the voice SYS_DRAFT/SYS_FIX), else 400; drop MAX_BODY to ~40 KB for user portals.
- **Deny / cost:** without the `EK_CAP` KV binding the cap lives per isolate (worker.js:60-64), so it multiplies across isolates and restarts: no real bound. KV read-then-write is not atomic (soft). One curl loop spends the whole day cap and silences the Ask button for every real visitor. **Fix:** refuse to serve (500 `no_cap_store`) without `EK_CAP`, or use a Durable Object / Cloudflare rate-limit binding; add a per-IP day limit keyed on a salted hash of `CF-Connecting-IP` (never logged); make "set a monthly spend limit on a dedicated Anthropic workspace/key" a numbered PROXY.md step, not a note. `parseInt(env.MAX_TOKENS)` NaN → NaN max_tokens: default on NaN. Read `Content-Length` before `request.text()`.
- **Disclose (Worker):** errors return only Anthropic's `error.type` and a mapped status; no key, no upstream body; SSE passed through untouched (no key in it); `LOG_ERRORS` logs status + type only. `proxy_has_no_key` is harmless. Model is env-pinned; effort and max_tokens clamped.
- **Disclose (direct key):** kept in plain `localStorage` on the page's origin: every page and script on clcabana.github.io (public sample and demo, any other repo's Pages, a compromised CDN script, extensions with site access) can read it in the person's browser, until "Forget key". Never logged, echoed, put in a URL or in an export (`EK.reactions()` reads only `ek:<slug>`); input is `type=password` and cleared. `setKey` refuses outside `PROJECT.portal=="admin"` (build-time constant); a user build in direct mode drops ek-chat (chain.py:79). **Fix:** keep the key in memory or `sessionStorage` by default, with an explicit "keep on this computer" opt-in; use a dedicated key with its own spend limit; only ever on a dedicated origin or localhost.
- **Disclose (records):** in the admin portal the drawer still records the person's questions and the assistant's answers (which quote sisters' notes with device ids) into `ek:<slug>`, the same store the user portal uses on that origin; "Merge with this browser's own record" then counts them as visitor questions. **Fix:** skip `EK.react` when `ADMIN`.
- **Transparency:** consent line names "the team's AI service" in proxy mode; name Anthropic and Cloudflare. Shell inlines the whole manifest `chat` block (ek-shell build.py:335) into every portal: whitelist `mode, proxy_url, provider, model, daily_cap`.
- **Elevate / repudiate:** n/a: no eval/innerHTML/tools; build.py reads `--brief`, rewrites `--out`; per-browser cap is advisory only.
