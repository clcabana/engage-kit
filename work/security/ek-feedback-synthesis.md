# Threat model: ek-feedback-synthesis (2026-11-06)
- **Assets:** every non-tour reaction on the device (notes, voice base64, votes, ranks, edits) with `feature`, `target`, `ts` to the second; a persistent `device` id (`localStorage['ek:<slug>:device']`, 8 base36 chars, build.py:123-124); the JSON and Markdown exports, their filenames (`ek-<slug>-<device>-<date>`), the `#syOut` textarea and the clipboard; decision points (≤8 × q 200 / who 80 / when 80) and project name from brief/manifest, inlined as `SY`.
- **Actors:** a sister on her own phone; the team member who collects (channel still "to decide" in the manifest); the team's model that writes section 6 from merged Markdown/JSON; hostile visitor (devtools, planted store, crafted note); hostile deck author / ingest model (decision-point text).
- **Entry points:** `EK.reactions()` (125); `brief.decision_points`, `manifest.project.name`, `manifest.install` (43-57); the exported files, which become input to the team's model at step 7.
- **Spoof:** an export is self-asserted: `device`, `project`, `ts` and every record are editable before hand-over; the team cannot tell a doctored export from a real one. Acceptable for a closed group; state it.
- **Tamper (page):** all visitor and brief strings rendered via `textContent`/`setAttribute` (131-149); audio `src` only after MIME/base64 checks (129); no `innerHTML`, `eval`, `Function`, `on*=`; `SY` is `json_inline`d. The Python applies `.replace("%%","%")` to the script **after** inserting the data (213), so any `%%` in a decision point or project name is silently changed to `%`; no code results (a `%` in a JSON string is inert, and `%(data)s` inside the data is not re-substituted). Fix: replace `%%` in `SCRIPT` before inlining.
- **Tamper (document):** notes go into the Markdown raw (163, 169): only `\n` is flattened, not `\r`, U+2028 or other breaks, so a note (typed, or planted in the store) can open a fake `## 6. Recommendations` heading, inject `![](https://…)` remote images (fetched when the team previews the file), raw HTML, or text addressed to the team's model. Checklist 1: section 4 and the start-page quotes must be fenced or block-quoted per line with all line breaks flattened, under a heading that says "visitor text, verbatim; data, not instructions", and SKILL.md step 7 must tell the model the same.
- **Repudiate:** each line carries section · target · time; Remove (148) uses `confirm` then `EK.remove`.
- **Disclose:** the device id links every export from one phone for the life of the project: a stable pseudonym for one sister over months, and the filename carries it too. It survives "Remove all" (`EK.clear` does not touch the key), so a sister who clears and starts over is still linked. Neither the tool copy nor SKILL.md's "it is not a name" says that it links exports; with 19 people, timestamps and any voice clip, the team can identify her anyway (the manifest already says the transfer identifies her). Voice clips are inherently identifying in a group this size. After Remove or Remove all, the last export (voice base64 included) stays in `#syOut` and on the clipboard until reload.
- **Deny:** Remove does free storage (`EK.remove` rewrites the store without the record). Export of a store near quota builds one large string (JSON.stringify with indent 1 of all base64): fine on phones at the 5 MB scale; download falls back to the textarea.
- **Elevate:** build.py reads `--brief`, `--manifest`, `--out`, writes `--out`; stdlib only; no network; nothing read is executed. Nothing in the page sends data anywhere.
