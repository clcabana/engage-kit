# Threat model: ek-site-massing-3d (2026-10-26)
- **Assets:** option ids/names/descriptions, block labels and dimensions, context blocks and site outline from the deck, inlined once as the `MS` JSON (build.py:220 → output/index.html:502) and as escaped tab markup (build.py:164-167 → index.html:290); the deck's option drawings as `data:` URIs (fallback `<img>` only); the visitor's one massing vote `{feature:'massing', target:'option-<id>', kind:'vote', value:1}` in `localStorage['ek:'+slug]`; the block-selection context (`ek:context`, never stored); three.js r128 (603,445 B) fetched from cdnjs on every visit; any image file under `--root` that `options[].image` names.
- **Actors:** anonymous visitor on a shared table phone; hostile visitor (devtools, planted store); hostile deck author (every `MS` string and number, image paths, via `work/brief.json`); cdnjs/Cloudflare and anyone who could tamper with it; design team running `build.py`; `ek-massing-markup`, which will call `EK.feature.massing` and feed `setDeltas()`.
- **Entry points:** `brief.options[]` → `options_from_brief()` (103-139); `brief.context_blocks` → `context_from_brief()` (142-151); `brief.site.outline_m` → `outline_from_brief()` (154-158); image bytes → `embed_image()` (49-90, Pillow optional); `EK.reactions()` → `mine()`/`choice()` (230-231); `window.THREE` (246); `EK.feature.massing` (313-314); `--brief`/`--out`/`--root` (operator). No `location.hash`, no visitor text, no loaders or textures.
- **Spoof:** n/a — no identities; a vote is one anonymous device, labelled "Your choice (this phone)" (232), toast "saved on this phone" (233), tour "One choice per phone" (329).
- **Tamper:** tabs: `data-opt`, `<b>`, `<small>` are `html.escape`d (165-166); `<h2>` is a number word, `.ms-about` a constant (186). `MS` is `json_inline`d (42-44: `</`, `<!--`, U+2028/9) and every string in it reaches the page via `textContent` or `createElement` only (hud 251, desc/meta 238, chip 232, fallback text 247, `EK.context` 240/256); `img.src` is only ever a build-made `data:` URI with allowlisted MIME (65, 239, 247). No `innerHTML`, `eval`, `Function`, `on*=` or `style` from data anywhere in the block. The one string handed to three.js is `css('--marker'|'--plan'|'--soft'|'--line')` → `Color.set()`, which comes from the shell's validated palette tokens, not the brief (r128 is past the CVE-2020-28496 colour-parse ReDoS fix in 0.125). A planted vote with a bogus `target` is ignored by `O.find` (232); many planted votes → `choice()` takes the last, and the next tap removes them all (233).
- **Repudiate:** `msMeta` prints "slide N" when `source_slide` exists (238), nothing otherwise; `source_slide` is passed untyped and uncapped (135), so an object prints "[object Object]" and a long string bloats the page — harmless via `textContent`, but cap it (`str(...)[:12]`). Duplicate option ids only warn (137-138); two options sharing `option-<id>` would share a vote target.
- **Disclose:** `embed_image()` now checks containment (56: UNC prefix, `root_r in path.parents`) and symlinks are resolved first — but `path.resolve()` at 52 runs **before** the UNC check at 56, and on Windows `realpath` opens the path, so an `options[].image` of `\\attacker\share\x.png` (or `//…`) makes the team's build machine open an SMB session to the attacker (NTLM hash exposure) before the warning fires. Rasters ≤200 KB (and all bytes when Pillow is absent) are embedded verbatim, EXIF included; JPEGs are always re-encoded (78). Drawings may show identifiable residents or children: same clearance as the timeline images. Every visit sends IP, user agent and (per the page's referrer policy, none set) the tool's URL to Cloudflare for `three.min.js`; `crossorigin="anonymous"` sends no cookies. A vote carries the shell's `id`+`ts` only.
- **Deny:** strings are capped (id 8, name 40, desc 160, label 40) and `num()` (95-99) rejects NaN/Infinity so no literal breaks the script; but counts and magnitudes are not: options, blocks per option, context blocks and outline points are unbounded (each block = one mesh + material + shadow, so a brief with 20,000 blocks freezes a phone), and `w`/`d`/`s`/`x`/`y` accept 1e9 (box far outside the 600 m camera far plane and the 400 m `dist` clamp at 286: the model is simply unviewable, `fit()` 285 does not throw; float32 jitter at 1e9). `Image.open` on a decompression bomb is caught (87-89) → warning. If three.js fails SRI, is blocked or the device is offline (including `file://` without network), `fallback()` (247-249) shows the drawing and a one-line note; tabs, vote and sun label keep working. A lone surrogate in a brief string makes `write_text` raise (367) — operator-only. `setDeltas()` from a later skill is used arithmetically without finite checks (253, 276-277): a NaN delta gives an invisible block, not a crash.
- **Elevate:** `build.py` reads `--brief`, `--out`, image files under `--root`, imports Pillow if present; writes `--out` only; stdlib otherwise, no subprocess, network, env or credentials (except the UNC `resolve()` above). SVGs are shown through `<img>` only. `window.build = undefined` (281 → index.html:563) is a stray line: it creates a global `build` property (contract says no globals) but does not shadow the local `build()` and runs nothing. `EK.feature.massing` hands `scene`, `camera`, `renderer`, `canvas` and the live `options` array to any later script on the page: acceptable for a single-origin file where every feature script already has full page rights by design; the extending skill must range-check its own deltas.
