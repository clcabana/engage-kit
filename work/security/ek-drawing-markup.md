# Threat model: ek-drawing-markup (+ synthesis additions) (2026-11-06)
- **Assets:** up to 8 deck drawings embedded as data: URIs (qop: four axons + the arborist's annotated base plan, which shows proposed building names including a residence, numbered trees and a handwritten date; no address, PID or contact visible); visitor strokes (0–1 points), labels (60 chars) and sketch photos (JPEG base64 ≤ 1.6 M chars) in `localStorage['ek:<slug>']`; JSON/Markdown exports; paper prints.
- **Actors:** a sister on her phone; the team collecting exports and its model; hostile visitor (devtools, planted store, crafted file); hostile deck/ingest (sheet names, SVG sheets); the arborist (third-party author of slide 17).
- **Entry points:** `brief.sheets[]` (build.py:104-137); pointer input; `window.prompt` (249); the file input (263-268); stored records on render (272-283); synthesis `valueText`/`photoOk`/Markdown block (ek-feedback-synthesis build.py:139-141, 195-196).
- **Spoof:** records are self-asserted per device, as for every feature; acceptable for a closed group.
- **Tamper (page):** sheet names/slide/text `html.escape`d or `textContent`; DM `json_inline`d. `pathEl` only emits `toFixed` digits; `mkOk` rejects NaN/±Infinity/1e308 in points (range −0.1..1.1). Text x/y are only `typeof number`, so NaN/1e308 reach `setAttribute("x")` as "NaN"/"Infinity": inert, but unbounded. Labels: SVG text nodes, sliced to 60; prompt input is a plain string. No innerHTML/eval/on*=. Photos rendered only after `imgOk` (jpeg + base64 charset).
- **Tamper (sheets):** SVG sheets pass `SVG_UNSAFE`; as `<image href>` / `<img src>` an SVG is in image mode (no script, no external fetch). Raster sheets are Pillow re-encoded: no EXIF/GPS in any of the 14 embedded JPEGs in the current qop output (checked).
- **Tamper (document):** markup labels go through `flat` then `quote` per line (196); sheet targets through `flat` only (same as other targets: a planted target could carry `![](https://…)` mid-line). `valueText` labels are in-page `textContent` only. The block sits in section 3, before section 4's "data, not instructions" heading.
- **Repudiate:** each markup/photo listed with time and Remove (`confirm` → `EK.remove`).
- **Disclose:** canvas re-encode drops the photo's metadata, but the pixels can still show faces, hands, a room, a child, a name on paper; no line tells the visitor to photograph only the paper. Publishing to Pages makes the arborist base plan (a third party's work, showing where a residence sits) public to anyone with the URL. Prints leave the phone on paper (the visitor's choice).
- **Deny:** quota failure rolls back and toasts (shell react 167). localStorage is ~5 MB per origin, shared by every tool on the Pages origin and with voice clips; one worst-case photo (1.6 M chars) takes a third to two-thirds of it, typical paper photos 0.2–0.5 M chars, so ~5–10 per phone; after that notes also fail. A 12 MB / 48 MP photo decodes to ~190 MB of bitmap before downscale (tab may crash on older phones). SVG/zero-size images give a 0×0 canvas ("data:," → empty base64 stored, shown as "Unsupported"); a tainted canvas throws uncaught in `onload`. Each sheet is embedded twice (figure `<img>` + `DM.sheets[].src`): 1.76 MB, not 880 KB, of the 4.46 MB page.
- **Elevate:** build.py reads brief + images under `--root` (containment checked), writes `--out`; no network; nothing read is executed; page sends nothing anywhere.
