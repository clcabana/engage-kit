# Threat model: ek-shell (2026-10-25)
- **Assets:** reactions in `localStorage['ek:' + slug]` (notes now; voice clips as base64, pins, votes, edits once features land); the inlined `PROJECT` object (name, phase, deadline, audience, palette, typeface, installed skills); the page itself once hosted on a public URL.
- **Actors:** anonymous visitor on a shared phone at a drop-in table; design team; client; hostile visitor; hostile deck author (deck text → `work/brief.json` → `build.py`); the model generating feature code against the Contract.
- **Entry points:** brief/manifest strings (`name`, `phase`, `deadline`, `one_line`, `palette`, `typeface`, `audience`, `install[]`) → markup, CSS and `PROJECT` JSON; visitor text via `#note` (maxlength 400, stored raw); `location.hash`; existing localStorage contents (tampered, or written by any other page on the same origin — `*.github.io` project pages all share one origin); feature `<script>` blocks at `ek:scripts`; the Google Fonts stylesheet request.
- **Spoof:** n/a — no identities; one device is one anonymous voice. `EK.react` lets the caller supply `id`/`ts` (`Object.assign({id,ts}, r)`, template.html:145), so a feature or console user can backdate or collide ids.
- **Tamper:** `typeface` is interpolated raw into `<style>` (build.py:170 → template.html:13); every other placeholder is `html.escape`d or constant and `PROJECT` is `json_inline`d with `</`, `<!--`, U+2028/9 neutralised. localStorage is user-writable; nothing stops editing counts or planting records that are not objects.
- **Repudiate:** records carry `id`+`ts` only; no device id, so the export cannot say how many devices spoke. Build time in `<meta generator>`.
- **Disclose:** notes are free text and may name neighbours or children; they persist on a shared table phone for the next visitor (nav badge shows the count). Google Fonts sends IP, user agent and the tool's URL to Google on every load. `PROJECT` holds nothing secret (no client name, no deck path).
- **Deny:** a non-object entry in the stored array throws in `counts()` at load (template.html:179-180, outside `emit`'s try/catch) and the nav never builds; a 5 MB store (voice base64) makes `save()` fail silently and reactions vanish.
- **Elevate:** `build.py` reads `--brief`, `--manifest`, `template.html`, writes `--out`; no subprocess, network, env or credentials. Shell JS has no `innerHTML`, `eval`, `Function`, or `on*=` from data; `EK.show`/`hashchange` use `CSS.escape`; `textContent` for ctx, hint, toast, nav, tour. Feature scripts run with full page rights by design.
